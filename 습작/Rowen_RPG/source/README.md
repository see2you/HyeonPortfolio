# mmorpg/ — 싱글 MMORPG 프로젝트 폴더

현의 다음 프로젝트 방향: **최신 모바일 MMORPG를 싱글 플레이로 재해석한 게임.**
이 폴더는 해당 프로젝트의 레퍼런스 분석, 기획 문서, 수치 설계, 프로토타입 관련 자료를 모아 관리한다.

> **다른 프로젝트로 이어서 작업한다.** 이 폴더는 버디 트래블러(2D HD RPG) 프로젝트 안에서 시작했지만 별도 게임이다.
> 이어 받는 쪽은 **`HANDOFF.md`부터** 읽는다 — 현재 상태, 다음 작업(인벤토리·캐릭터 창 포함), 소스 구조, 빌드·테스트 방법, 교훈을 모두 담았다.
> 옮길 파일: `mmorpg/` 전체 (HANDOFF.md · README.md · reference/ · proto/). `proto/art.js`는 버디 트래블러 `src/game.js`에서 떼어 온 아트 코드라 함께 옮긴다.

## 방향 (2026-11-13 기준)
- 모바일 MMORPG의 문법(필드 사냥터·레벨대별 존, 자동전투, 스탯 배분, 퀘스트 NPC, 포션 상점, 보스, 성장 연출)을 서버 없이 싱글로 구현
- 레퍼런스: 〈달그늘 고개〉(moonlit-pass-rpg-demo) — 단일 HTML 캔버스 쿼터뷰 액션 RPG 데모
- 레퍼런스: 〈제우스: 오만의 신〉 — Claude Docs 「인수인계: 제우스 분석 기반 신규 게임 설계」(https://claude.ai/artifact/1QNH9WmWxrGSDV8NQEpJeU). 요약·반영 현황은 `reference/zeus-handoff.md`
- 아트: 버디 트래블러의 코드 픽셀아트 리소스를 HD-2D(3D 지형 + 픽셀 스프라이트) 방식으로 재사용
- 싱글 모드에서는 PvP·콜로세움을 넣지 않는다 (v4 결정)
- 회복 물약은 보상으로 주지 않고 상점에서만 산다 — 사냥 중 물약 압박을 유지 (v4.1 결정)
- 침공은 Lv20부터, 보스 레벨은 플레이어 레벨에 연동 (v4.2 결정)
- 수동 조작은 퀘스트 자동 진행을 끈다. 성장 알림은 트래커가 아니라 버튼 빨간 점으로만 (v4.3 결정)
- 사망은 팝업 → '부활하기'로 마을 부활, 사망 위치엔 묘지 십자가. 긴급 귀환(자동 주문서)은 기본 끔 (v4.4–4.5.2 결정)
- 지역 3개: 로웬(Lv1–16) · 카르도(16–28) · 에르나(28–40, 만렙) (v4.5)
- 리니지 라이크 아이템: 장비 9부위 드롭 · 마법 주문서 강화(파괴 없음) · 무게 · 리니지M식 가방 UX. 창을 연 동안 전투 정지 · 스킬 차수 탭 · 슬롯 8칸 (v4.8 결정)
