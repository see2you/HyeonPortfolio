## 1. 레퍼런스 화면 분석

### 1-1. 메인 화면 (ref1)

![레퍼런스 메인 화면](참고이미지/ref1_메인화면.png)

| 위치 | 요소 | 내용 |
|---|---|---|
| 좌상 | **캐릭터 카드** | 초상화(알림 `!` 배지) · `Lv. 4 하람 · 등불지기`(이름·직업) · HP 바 · MP 바 · `HP 100/100 MP 80/80` · EXP 바 `198/270`. **카드를 터치하면 능력치 창**이 열림 |
| 상단 좌측 | 재화 칩 | `엽전 341` (재화 1종만 크게) |
| 상단 중앙 | 지역명 | `✧ 꽃담 마을 ✧` 장식 배너 |
| 우상 | **메뉴 버튼 줄** | `스킬 · K ●`(빨간 점 = 배울 수 있음) · `능력치 · C +9`(남은 포인트 수를 버튼에 표시, 금색 강조) · `지도 · M` · `동작 보기` · `조작법` · `설정` |
| 우상 아래 | 미니맵 | 원형, 지역명 라벨, 방위(N), 상점 아이콘, `휠로 지도 확대·축소 · 100%` |
| 좌측 | 퀘스트 | `◇ 고개의 등불 · 등불 조각 0/6` 한 줄 카드 |
| 좌측 아래 | 카메라 | `‹ ▲N 0° ›` 회전 · `100%` 줌 |
| 좌하 | 조이스틱 | 원형 |
| 하단 중앙 | 물약 | `HP 6 / 3개` · `MP 7 / 3개` 카드(단축키 숫자 + 보유 수) |
| 우하 | **스킬 슬롯 5칸** | `달빛 베기 1` · `혼불 2` · `빈 슬롯 3/4/5`(점선 원 + `+`) — 슬롯 번호 = 단축키 |
| 우하 | 행동 버튼 | `순보 Space`(대시) · `스캔 F`(주변 타겟) · `평타 Z`(가장 큼) · `AUTO 꺼짐` 토글 |
| 최하단 | 조작 안내 | `WASD 이동 · Space 순보 · G 대화 · M 지도 · Z 평타 · 1~5 스킬 · K 수련 · Tab 주변 타겟 · F 스캔 · R 자동 · Q/E 우클릭 회전 · 휠 확대·축소` |

**포인트**
- 성장 알림을 **버튼 자체에** 붙인다: 스킬은 빨간 점, 능력치는 `+9`처럼 숫자. 트래커 카드를 쓰지 않는다(우리 v4.3 결정과 같은 방향).
- 스킬 슬롯이 '빈 슬롯'으로 보여 **아직 배울 스킬이 있다**는 걸 화면에서 계속 알려 준다.

### 1-2. 능력치 창 (ref2) — 캐릭터 카드 터치 또는 `C`

![레퍼런스 능력치 창](참고이미지/ref2_능력치창.png)

- 머리: 소제목 `CHARACTER / GROWTH`, 제목 `능력치`, 닫기 `×`.
- 요약 줄: `Lv. 4 · 하람` · `경험치 198 / 270` + 경험치 바 · 우측 **`남은 포인트 9`** 박스.
- 좌측 **스탯 4행**: 이름(영문 약자 · 한글) + 효과 한 줄 + `– 0 +` 스테퍼.
  - `STR · 힘` 평타 +2 · 최대 HP +10
  - `DEX · 민첩` 회피 +0.5%p · 치명타 +0.4%p
  - `INT · 지력` 도술 피해 +3 · 최대 MP +8
  - `LUK · 행운` 치명타 +0.3%p · 치명타 피해 +2%p
- 우측 **`전투 능력 · 적용 전 → 적용 후`** 표: 평타 피해 · 스킬별 피해(달빛 베기·혼불) · 최대 HP · 최대 MP · 회피율 · 치명타 확률 · 치명타 피해. 스테퍼를 누르면 '적용 후' 값이 바로 바뀌는 미리보기.
- 하단 안내: `레벨업마다 3포인트 지급 · + / –로 배분한 뒤 적용하세요` · `회피율 최대 35% · 치명타 확률 최대 60% · 피해는 치명타·방어·변동 적용 전 기준` · `이 브라우저에 성장 정보가 자동 저장됩니다` · **`창을 연 동안 전투가 일시 정지됩니다. 닫으면 미적용 배분은 취소됩니다.`**
- 확정 버튼 `배분 적용`(우하, 금색).

**포인트**: ① 임시 배분 → `배분 적용`으로 확정하는 **2단계**(실수 방지) ② 적용 전/후 비교 ③ 상한값 명시 ④ 창 열면 전투 일시 정지.

### 1-3. 스킬 수련 창 (ref3) — `스킬` 버튼 또는 `K`

![레퍼런스 스킬 수련 창](참고이미지/ref3_스킬수련창.png)

- 머리: 소제목 `PATH OF THE LANTERN`, 제목 `스킬 수련`, 우측 `Lv. 4 · 견습 등불지기`(칭호) · **`스킬 포인트 9`** · 닫기.
- **차수 탭 5개**: `1차 Lv.10` · `2차 Lv.30` · `3차 Lv.50` · `4차 Lv.70` · `5차 Lv.100` — 각 탭에 해금 레벨과 `미개방` 상태.
- 탭 설명: `1차 스킬 · 총 5개` / `Lv. 10 달성 후 혜명의 전직 퀘스트를 완료하세요.` + 우측 버튼 `해당 찾아가기`(전직 NPC로 자동 이동, 미개방이면 비활성).
- 좌측 **스킬 목록**(카드 5개): 아이콘 · 이름 · 분류(`검술 · 전방 단일`, `도술 · 유도 투사체`, `도술 · 범위`, `도술 · 연쇄`, `도술 · 흡수`) · 상태 `잠김`. 선택한 카드는 금색 테두리.
  - 1차 예: 초승 가르기 · 청혼탄 · 월영진 · 청뢰술 · 생기 흡수
- 우측 **상세 패널**: 큰 아이콘 · 분류 · 이름 · `미습득 · 아래 수치는 Lv. 1 기준` · 설명 한 줄 · 수치 카드 4칸(`기본 피해 + INT 보정 · 1타 40` · `발동 접근 거리 2m` · `MP 소모 9` · `재사용 대기 4초`) · **최종 각성 박스**(`Lv. 20 · 최종 각성` — 후속 참격 60%, 이펙트 색 변경) · 버튼 `배우기 · 1P`(우상).
  - 안내: `아래 5개 슬롯 중 원하는 곳을 누르면 장착됩니다. 이미 장착된 스킬은 서로 자리를 바꿉니다.`
- 하단 **슬롯 바**: `먼저 스킬을 배운 뒤 슬롯을 선택하세요` · `기본 기술 선택 [달빛 베기] [혼불]` · `슬롯 1·1키 … 슬롯 5·5키` 5칸(장착 스킬 이름 + `×` 해제, 빈 칸은 `+ 빈 슬롯`).
- 바닥글: `레벨업마다 스킬 3P · 배우기/강화 1P · 최대 Lv. 20 · 자동전투는 슬롯 순서대로 사용` · `창을 연 동안 전투가 일시 정지됩니다.`

**포인트**: ① 차수(전직) 구조로 장기 목표를 한 화면에 ② 미습득이어도 수치·각성 효과를 미리 보여 줌 ③ **습득과 장착 분리** — 배운 스킬을 5슬롯에 직접 배치, 자동전투 우선순위 = 슬롯 순서 ④ 스킬 최대 Lv.20 + 최종 각성.

## 2. 우리 게임 적용 기획

### 2-1. 현재 상태와 바꿀 점
| 항목 | 현재(v4.5.2) | 바꿀 방향 |
|---|---|---|
| 능력치 | 미니맵 아래 `능력치` 버튼 / C → NPC 대화창과 같은 하단 모달, +1/+5 즉시 반영 | 좌상 캐릭터 카드 터치 + 상단 메뉴 `능력치 · C +n` → **전용 능력치 창**(임시 배분 → 적용, 전/후 비교) |
| 스킬 | `스킬` 버튼 / K → 모달, 배우기·강화 | 상단 메뉴 `스킬 · K ●` → **스킬 수련 창**(목록 + 상세 + 슬롯 장착) |
| 스킬 슬롯 | 5종 고정 배치(스킬 = 슬롯) | **습득 ≠ 장착**. 슬롯 5칸에 배치, 빈 슬롯 표시, 자동전투 순서 = 슬롯 순서(설정에서 변경) |
| 알림 | 버튼 빨간 점(능력치·스킬) | 능력치는 **남은 포인트 숫자**(`+3`), 스킬은 빨간 점(배우기/강화 가능할 때만 — 현행 유지) |
| 설정 | 없음(상점 안에 '자동 진행 보충'·'긴급 귀환' 토글) | 상단 `설정` → **전투 설정 패널**로 자동 전투·자동 진행 관련 토글을 모음 |
| 메뉴 위치 | 미니맵 아래 2줄 버튼(귀환·확대·초기화 / 능력치·스킬·권능) | **우상단 메뉴 줄**로 이동, 미니맵은 그 아래 |

### 2-2. 상단 메뉴 줄 (우상단)
순서: `스킬 · K ●` · `능력치 · C +n` · `가방 · I` · `권능 · P` · `지도 · M` · `설정`
- `가방`은 인벤토리 창(2-6, 다음 단계). `지도`는 지역 전체 지도(현재 미니맵 확대 Z를 대체 검토).
- 귀환(B, 주문서 수 표시)·초기화는 미니맵 아래에 남기거나 설정 안으로.
- 남은 능력치 포인트 > 0이면 `능력치` 버튼 금색 강조 + `+n`.
- 모바일: 버튼 높이 최소 44px, 단축키 표기는 터치 기기에서 숨김.

### 2-3. 능력치 창 (캐릭터 카드 터치 · C)
- 머리: `CHARACTER / GROWTH` · `능력치` · `Lv. n · 원정대원` · 경험치 바 · `남은 포인트 n`.
- 스탯 4행(우리 스탯 그대로): 
  | 스탯 | 효과 표기 |
  |---|---|
  | 힘 · STR | 공격력 +2 |
  | 체력 · VIT | 최대 HP +14 · 방어 +0.6 |
  | 민첩 · DEX | 치명 +0.5%p · 공격 속도 +0.8% |
  | 지력 · INT | 스킬 피해 +1.5% · 최대 MP +5 |
  - 스테퍼 `– n +`(길게 누르면 연속), 이번 배분분만 `–` 가능(확정된 포인트는 되돌리지 않음 — 초기화는 별도).
- 우측 `전투 능력 · 적용 전 → 적용 후`: 공격력 · 방어 · 최대 HP · 최대 MP · 치명 확률 · 공격 속도 · 스킬 피해 배율 · 스킬별 1타 피해(장착 슬롯 기준) · **전투력**. 바뀌는 값은 금색 + `▲`.
- 버튼: `추천 분배`(임시 배분에 채움) · `배분 적용`(확정). '자동 성장' 토글은 이 창 하단으로 이동.
- 안내: `레벨업마다 3포인트` · 상한(공격 속도 최대 +40%) · `닫으면 미적용 배분은 취소`.
- (선택) 능력치 초기화: 골드 비용(레벨 비례) — 골드 소모처 후보.

### 2-4. 스킬 수련 창 (스킬 버튼 · K)
- 머리: `스킬 수련` · `Lv. n · 칭호` · `스킬 포인트 n`.
- **차수 탭**(우리 지역 구조에 맞춤 — 제안):
  | 탭 | 해금 | 스킬 |
  |---|---|---|
  | 1차 · 로웬 | Lv1~ | 회오리 베기(Lv2) · 돌진 찌르기(Lv4, 스킬서) · 별똥별(Lv7) · 전투 함성(Lv11, 스킬서) |
  | 2차 · 카르도 | Lv16 + 메인 13 | 대지 가르기(Lv18, 스킬서) + 신규 1~2종 |
  | 3차 · 에르나 | Lv28 + 메인 23 | 신규 2~3종 — Lv30 이후 스킬 성장 정체 해소(HANDOFF ③) |
  - 미개방 탭은 해금 조건과 `해당 찾아가기`(해금 퀘스트 NPC로 자동 이동) 버튼.
- 좌측 목록: 아이콘 · 이름 · 분류(예: `검술 · 주변 범위`, `검술 · 돌진`, `마법 · 지정 범위`, `버프`, `검술 · 일직선`) · 상태 배지(`잠김 Lv7` / `스킬서 필요` / `배우기 가능` / `Lv3/5` / `최대`).
- 우측 상세: 분류 · 이름 · 상태 · 설명 · 수치 카드(1타 피해(현재 능력치 반영) · 범위/사거리 · MP · 재사용 대기) · 다음 단계 미리보기(`Lv3 → Lv4: 피해 +12%, 필요 캐릭터 Lv 13`) · 최종 단계 효과(신의 권능 변형도 여기 표시) · 버튼 `배우기 · 1P` / `강화 · 1P` / 불가 사유(`캐릭터 Lv 13 필요`, `스킬서 필요 — 서브 「대장장이의 시험」`).
- 하단 슬롯 바 5칸: 상세에서 스킬을 고른 뒤 슬롯을 누르면 장착, 장착된 스킬끼리는 자리 교환, `×`로 해제. 빈 칸 `+ 빈 슬롯`.
- 바닥글: `레벨업마다 스킬 포인트 1 · 배우기/강화 1P · 최대 Lv 5 · 자동전투는 슬롯 순서대로 사용`.
- HUD 스킬 버튼은 **슬롯 기준**으로 그린다(현재는 스킬 고정 위치). 빈 슬롯은 점선 원 `+` → 누르면 스킬 수련 창.

### 2-5. 전투 설정 패널 (설정)
상단 메뉴 아래 드롭다운. 레퍼런스 항목을 우리 자동 기능에 맞춰 재구성:
| 묶음 | 항목 | 형식 | 기본값 | 현재 위치 |
|---|---|---|---|---|
| 자동 전투 | 타겟 범위 | 선택(가까이/보통/넓게) | 보통 | 코드 고정값 |
| 자동 전투 | 타겟 우선 | 선택(퀘스트 대상 우선/가까운 순/약한 순) | 퀘스트 대상 우선 | 코드 고정 |
| 자동 전투 | 스킬 사용 순서 | 선택(슬롯 1→5 / 쿨 짧은 순 / 강한 순) | 슬롯 1→5 | 코드 고정(함성→대지→별똥별→돌진→회오리) |
| 자동 전투 | 몬스터 자동 반격 | 체크 | 켬 | 항상 켬 |
| 물약 | HP 물약 자동 사용 기준 | 선택(30/40/50/60%) | 40% | HP 물약 버튼 길게 누르기 |
| 물약 | 자동 진행 물약 보충 | 체크 + 목표 수 | 켬 · 한도까지 | 상점 안 |
| 물약 | 긴급 귀환 | 체크 | 끔 | 상점 안 |
| 진행 | 퀘스트 자동 진행 | 체크 | 끔 | 트래커 토글(유지) |
| 진행 | 자동 성장(능력치·스킬) | 체크 | 끔 | 능력치 창 |
| 기타 | 효과음 · 화면 흔들림 | 체크 | — | 없음 |
- 설정은 세이브에 저장(`S.cfg`).

### 2-6. 인벤토리(가방) 창 — 다음 단계 (요약)
- 탭: 소모품(HP/MP 물약·귀환 주문서 — 사용 버튼) · 재료(강화석·권능 파편·퀘스트 수집품) · 스킬서(획득 → '사용'하면 습득 가능해짐) · 장비(장비 드롭 도입 시).
- 데이터: 흩어진 `S.hpPot`·`S.mpPot`·`S.scroll`·`S.stone`·`S.shard`·`S.books`를 `S.inv`로 모으고 세이브 이전.

### 2-7. 공통 규칙
- **창을 여는 동안 전투 일시 정지**(레퍼런스와 같게). 단, 퀘스트 자동 진행 중이면 창을 닫을 때 이어서 진행. AI 모드·침공 타이머도 정지.
  - 확인 필요: 실시간성을 살리려면 '마을 밖에서는 정지하지 않음' 옵션도 가능 — 결정 사항으로 남김.
- 창 레이아웃: 큰 패널(화면 85~90%), 머리에 영문 소제목 + 한글 제목, 닫기 `×`(Esc). 모바일 세로 화면에서는 좌우 2단 → 위아래 1단.
- 미리보기 우선: 바꾸기 전에 결과(적용 후 수치, 다음 단계 효과)를 보여 준다.
- 성장 알림은 버튼(빨간 점·숫자)으로만. 트래커에는 넣지 않는다.
- 자동 기능이 무언가를 바꿨으면 토스트로 알린다(v4.5.2 교훈).

## 4. 결정이 필요한 것
1. 창을 연 동안 전투 정지 여부(전부 정지 / 마을 밖에선 계속).
2. 차수 탭 구조 채택 여부와 2·3차 신규 스킬 수(스킬 확장과 함께 결정).
3. 스킬 최대 단계(현재 5, 레퍼런스 20 + 각성).
4. 능력치 초기화 비용(골드 소모처로 쓸지).
5. 메뉴 줄에 `지도`(전체 지도 창)를 새로 만들지.

## 5. 결정 (2026-11-15 · v4.8 구현)
1. 창을 연 동안 전투 정지 → **전부 정지** (AI 모드·침공 타이머 포함, 게임 시간 t 자체를 멈춤).
