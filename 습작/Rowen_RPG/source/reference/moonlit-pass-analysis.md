## 3. 공식
- 필요 EXP: `60 + 40(L−1) + 10(L−1)²`, 만렙 999
- HP `100 + STR×10`, MP `80 + INT×8`
- 평타 `21 + STR×2`, 스킬 `기본 + INT×3`
- 피해: `power × U(0.9,1.1) × (치명 ? critDmg : 방어 ? 0.5 : 1)`, 빗나감 4.5%, 방어 10%
- 치명 `min(60%, 18% + DEX×0.4%p + LUK×0.3%p)`, 치명 피해 `1.65 + LUK×0.02`
- 회피 `min(35%, 3% + DEX×0.5%p)`
- 회복: MP 3.5/초 상시, HP 2.2/초(피격 후 5초 경과 시)
- 몬스터: 공격 주기 2.2초(보스 1.55), 타격 판정 0.43초, 판정 거리 2.4 / 집에서 40칸 이탈·플레이어 마을 진입 시 귀환하며 HP 전부 회복 / 리스폰 18초

## 4. 잘 된 점
같은 레벨의 몬스터 기준으로 레벨업에 필요한 처치 수가 초반엔 빠르고 Lv5 이후 7~8마리로 수렴:
토끼 3.0 → 사슴 5.6 → 돼지 6.9 → 늑대 7.3 → 호랑이 7.6 → 묘인 7.7 → 좀비 7.8 (Lv13까지 누적 EXP 8,420)

## 5. 문제점
1. **엔딩과 성장 콘텐츠가 끊겨 있음** — 퀘스트를 받은 뒤엔 어떤 처치든 조각이 1개씩 나와 토끼 6마리면 끝나고, 보스는 Lv1 지역에 나오며 HP 290으로 돼지 수준. 처치하면 리스폰도 멈춤. Lv2~3, 2~3분에 클리어 가능하고 Lv4~13 존은 클리어와 무관.
2. **STR이 정답 스탯** — 포인트당 DPS가 STR +3.3, INT +1.35로 2.5배 차이에 STR은 HP까지 줌. 36포인트를 몰아주면 STR은 DPS 133·HP 460, INT는 DPS 94·HP 100. DEX/LUK는 포인트당 피해 기대값 +0.26% / +0.55%로 함정.
3. **포션 가격 고정 → 경제 부재** — Lv13에서 HP 포션은 초당 69 회복인데 받는 피해는 초당 11 정도. 골드 수급은 7.5배 늘어나는데 쓸 곳은 포션뿐.
4. **방어 계층 없음** — 몬스터 피해 편차·방어력·레벨 차이 보정이 없어 레벨을 높이면 그냥 쉬워짐.
5. **안전지대 악용** — 마을 안에선 피격 판정이 꺼지고 몬스터는 귀환 시 HP를 회복해 다리 근처에서 끌어당겨 싸우기 쉬움.

## 6. 우리 프로젝트에 가져갈 시사점
- 엔딩·보스를 최상위 존과 연결 (조각을 특정 존·종족 전용 드롭으로, 보스는 최종 존 안에 HP 3,000 이상)
- 스탯마다 역할을 분리하고 포인트당 효율을 맞춤 (INT 계수 상향 또는 STR 평타 계수 하향 + 방어 성격 부여)
- 골드 사용처 다변화 (장비·강화·소모품을 레벨 비례 가격으로)
- 레벨 차이 피해 보정 계수 도입 (레벨 차이 1당 ±5% 등)
- 모바일 MMO 문법 체크리스트: 자동전투 앵커/귀환, 스킬 우선순위, 반격, 선공/비선공 혼합, 존별 밀도, 레벨업 연출 — 레퍼런스가 잘 구현한 부분이라 계승
