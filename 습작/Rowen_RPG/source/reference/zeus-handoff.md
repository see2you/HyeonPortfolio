# 제우스: 오만의 신 — 분석 인수인계 문서 요약 (싱글 MMORPG 기준 자료)

- 원문: Claude Docs 「인수인계: 제우스 분석 기반 신규 게임 설계」 https://claude.ai/artifact/1QNH9WmWxrGSDV8NQEpJeU (2026-11-13, 현)
- 조사 기준일 2026-11-03~05. 공개 기사·공략 기준이며 상당수가 출시 시점 값 → 구조와 비율만 참고한다.
- 함께 볼 문서: 「콘텐츠 기조 제안」(원문에서 링크)
- 이 파일은 원문의 요지를 프로토타입 작업용으로 옮겨 둔 것이다. 판단이 갈리면 원문을 본다.

## 1. 레퍼런스 요약
- 다수의 작은 성장 축을 누적하고, 개인·길드·서버 경쟁으로 소비처를 만드는 리니지라이크 MMORPG. 에이버튼 개발·컴투스 퍼블리싱, 2026-08-26 출시(PC·모바일).
- 핵심 차별점: 게임 종료 후에도 최대 12시간 사냥하는 **AI 모드**, **페르소나 기반 비동기 경쟁**.
- BM: 의상·탈것 소환, 유료 장신구, 멤버십, 시즌패스, 패키지. 장비·스킬은 현금 직접 판매 배제.
- 출시 후 약 2개월간 주 단위 업데이트 — 초반엔 성장 축, 10월부터 길드·서버 경쟁 콘텐츠.

## 2. 시스템 묶음 (분석용 분류)
- 성장: 장비(강화·축성·신석·신성력·아티팩트) · 캐릭터(스킬북 습득·+10 강화, 클래스 특화) · 영구(신과 210단계·에테리온·운명의 실타래·교단·점성술) · 생산·수집(제작·컬렉션) · 소환(의상·탈것).
- 콘텐츠: 사냥(일일 재료 던전, 인터서버 분쟁 사냥터, 시간제 협동·침공 보스) · 오디세이아(무한의 탑·시련의 전당·콜로세움·길드 레이드) · 길드·서버(아지트·성물 방어전·점령전·공성전) · 경제(거래소·미다스의 금고).

## 3. 재화 설계 원칙
- **모든 재화에 생성처와 소비처를 짝지어 둔다.** 레퍼런스에서도 소비처가 미확인인 재화(길드 코인, 사금·연마제, 영혼의 파편 등)가 흐름이 약한 지점이다.
- 공용 재료(오리하르콘처럼 여러 성장이 나눠 쓰는 재료)의 다중 경쟁은 신규 유저 판단 비용을 키운다 → 핵심 재화별 주 사용처를 지정한다.

## 4. 참고 수치 (출시 시점 위주 — 그대로 쓰지 말 것)
| 시스템 | 항목 | 수치 |
|---|---|---|
| 장비 강화 | 안전 강화 | 무기·방어구 +5, 장신구 +1 (초과 실패 시 파괴) |
| 스킬 | 최대 강화 | +10, 일정 단계부터 실패 시 하락 |
| 신과 | 최대 단계 / 성공 확률 | 210, 5단계마다 분기 / 인내 11단계 85%, 용기 5단계 60% |
| 신과 | 실패 보정 | 3회 연속 실패 시 +5%p |
| 오리하르콘 | 일일 채광 상한 | 25개 |
| 침공 보스 | 1회 보상 | 오리하르콘 15, 신과 파편 100·결정 50·정수 10 |
| 거래소 | 수수료 | 7% (일부가 공성전 상금 재원) |
| AI 모드 | 이용 시간 | 기본 12시간, 멤버십 24시간 |
| 무료 소환 | 일일 횟수 | 의상·탈것 각 5회 |

## 5. 설계 기조 — 따라 할 것과 바꿀 것
| 구분 | 레퍼런스 요소 | 판단 | 이유 |
|---|---|---|---|
| 따라 할 것 | 콘텐츠 → 재화 → 성장 → 상위 콘텐츠 순환 | 유지 | 성장 동기와 소비처를 함께 만듦 |
| 따라 할 것 | 페르소나 기반 비동기 경쟁 | 유지 | PvP 부담 없이 경쟁 |
| 따라 할 것 | AI 모드와 오프라인 성장 | 유지 | 접속 부담 감소 |
| 따라 할 것 | 장비·스킬 현금 판매 배제 | 유지 | 플레이 가치와 경제 보호 |
| 바꿀 것 | 15개 이상의 병렬 성장판 | 축소·통합 | 우선순위 판단이 어렵고 숙제화 |
| 바꿀 것 | 공용 재료의 다중 경쟁 | 사용처 정리 | 신규 유저 판단 비용 |
| 바꿀 것 | 사용처가 불분명한 재화 | 추가 금지 | 생성·소비 짝 설계 |
| 바꿀 것 | 능력치만 오르는 성장 | 플레이 변화형으로 | 수치 인플레이션·지루함 방지 |

**콘텐츠 판단 기준** — 아래 5문항 중 3개 이상 답이 있을 때 후보로 올린다.
1. 플레이가 달라지는가 2. 기존 재화 순환에 도움이 되는가 3. 대상 유저층이 명확한가 4. 일일 부담을 줄일 수 있는가 5. 격차와 경제를 통제할 수 있는가

## 6. 신규 콘텐츠 후보
| 후보 | 내용 | 참고 | 우선순위 | 프로토타입 상태 |

**신의 성역 초기 밸런스 가정** (시뮬레이션 출발점)
| 항목 | 가정값 | 목적 |
|---|---|---|
| 보호 구간 | 일일 생산량의 70~80% | 패배해도 기본 성장 유지 |

| 매칭 | 성장도 구간 기준 | 하위 유저 사냥 방지 |

## 7. 원문이 제시한 다음 작업 순서
레퍼런스 보완 → 성장 구조 확정(성장 시스템 수·묶음, 핵심 재화별 주 사용처, 해금 순서와 레벨 구간) → 재화 시뮬레이션(재화별 일일 생성·소비 Excel 모델, 과금 구간별 성장 곡선, 성역 생산·약탈 기대값) → 프로토타입과 검증.

**검증 지표**
| 대상 | 지표 |
|---|---|
| 성장 구조 | 성장 시스템별 투자 분포, 첫 막힘 구간 |
| 재화 순환 | 재화별 생성·소비 비율, 거래소 시세 |
| 일일 부담 | 일일 콘텐츠 완료율, 평균 소요 시간 |
| 신의 권능 | 권능 선택 분포, 프리셋 사용률 |
| 신의 성역 | 피약탈 유저 재접속률, 상위 1% 수익 집중도 |

## 8. 싱글 프로토타입에 반영한 것 (v3~v4.5)
- 재화마다 주 사용처 1개: 골드(물약·강화·각성), 강화석(강화), 권능 파편(각성). 투기장 코인은 콜로세움과 함께 v4에서 제거.
- 장비 강화: +5 안전, +6~+10 확률, **파괴·하락 없음**(레퍼런스 파괴 규칙은 '바꿀 것'), 3연속 실패 +5%p(신과 보정 차용).
- 신의 권능 3종(우선순위 1 후보) — 플레이 변화형 성장.
- 침공 보스(시간제 필드 보스) — Lv20 개방, 레벨 연동.
- AI 모드 — 오프라인 최대 12시간, 효율 40%, 사냥터 레벨 초과 시 경험치 감소.
- 페르소나 비동기 경쟁(콜로세움)은 싱글 모드에 불필요하다고 판단해 제거. 신의 성역의 약탈 대상(페르소나)으로 다시 쓸 수 있음.

## 9. 미확인 정보·리스크 (원문)
- 공식 가이드와 게임 내 메뉴를 직접 대조하지 못함. 클래스 특화, 신성력, 시련의 전당 보상, 일부 재화 사용처, 스킬 강화 재료, 신과 현재 비용이 미확인.
- 리스크: 출시 시점 수치를 현재 값으로 오인 / 레퍼런스 그대로 복제 / 내부 지표 부재 / 약탈형 경쟁 도입 시 피해 유저 이탈 / 공용 재화 다중 사용.
