목적 개요 곱 연산 / 합 연산 스탯 정리 BOOST 계산 방식 스탯의 오픈 스팩 수량 (74 개) 스탯의 변경 또는 추가 사항 계산 파이프 라인 전투력 책정

[콘텐츠 Power 및 데미지 계산 변경]

Confluence 페이지 오프라인 사본 · 이미지·영상 내장 · 인터넷 연결 없이 열람 가능

목적

콘텐츠 개방 및 콘텐츠에서 스탯 양이 증가함에 따라, 증가 폭이 체감이 되도록 하기 위함.

개요

  1. DAMAGE / DEFENSE / LIFE 계산방식 수정

    1. 이경호의 초기 값 + (골드성장, 코어성장, 슬롯강화) 스탯을 기준으로 그 외 콘텐츠에서 획득한 BOOST 스탯을 모두 곱하는 곱 연산 방법으로 변경

    2. 그 외 스탯은 합 연산

  1. 스탯 분류 (23종 분류)

    1. DAMAGE : 공격력

    2. DEFENSE : 방어력

    3. LIFE : 체력

    4. DAMAGE_BOOST : 공격력 증가

    5. DEFENSE_BOOST : 방어력 증가

    6. LIFE_BOOST : 체력 증가

    7. STR : 근력

    8. DEX : 민접

    9. INT : 지능

    10. STR_BOOST : 근력 증가

    11. DEX_BOOST : 민첩 증가

    12. INT_BOOST : 지능 증가

    13. DAMAGE_INCREASE_PVP : PVP 피해 증가

    14. DAMAGE_INCREASE_PVE : PVE 피해 증가

    15. DAMAGE_DECREASE_PVP : PVP 피해 감소

    16. DAMAGE_DECREASE_PVE : PVE 피해 감소

    17. DAMAGE_BOOST_TO_MONSTER_BOSS : 보스 몬스터 피해 증가

    18. CRITICAL_CHANCE : 치명타 확률

    19. CRITICAL_RESIST : 치명타 저항

    20. CRITICAL_DAMAGE : 치명타 피해

    21. DODGE : 회피

    22. DODGE_RESIST : 회피 저항

    23. FLAT_PENETRATION : 고정 관통

  1. 전투 공식 수정 및 스탯 추가 및 변경

    1. 공식 변경

      1. 데미지 계산

      2. 치명타 계산

      3. 치명타 계산피해 증가

      4. 회피 계산 변경

      5. 피해 증가 / 피해 감소 공식 변경

    2. 스탯 변경 사항

      1. 관통 스탯 추가 (관통 %)

      2. 회피 저항 추가 (4에서 설명)

      3. 근력(STR) / 민첩(DEX) / 지능(INT) 추가

      4. 근력(STR) / 민첩(DEX) / 지능(INT) BOOST추가

        1. ex )

          1. 최종 STR = STR * (1 + STR_BOOST / 100)

      5. 근력(STR) / 민첩(DEX) / 지능(INT) 으로 성장하는 스탯 추가

      6. 그 외 추가 스탯

  1. Miss 개념 추가

곱 처리

  1. 곱 연산 방식 요약

    1. 스탯 키 이름이 DAMAGE_BOOST, DEFENSE_BOOST, LIFE_BOOST 로 시작하는 모든 스탯은 곱연산 처리합니다

곱 처리 방식

  1. 같은 구분 값으로 묶은 스탯 값들은 합하여 DAMAGE / DEFENSE / LIFE 에 곱으로 처리

    1. 연산 시 (1 + Ratio) 형태로 변한 뒤 곱합니다.

    2. ex) 최종 데미지

      1. Damage * ( 1 + ( 구분Base /100)) * ( 1 + ( 구분1 /100))* ( 1 + ( 구분2 /100))* ( 1 + ( 구분3 /100))* ( 1 + ( 구분4 /100))* ( 1 + ( 구분5 /100))* ( 1 + ( 구분6 /100))* ( 1 + ( 구분7 /100))
