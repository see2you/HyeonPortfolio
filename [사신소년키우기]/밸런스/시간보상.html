플레이 지원(온/오프라인 시간) 보상

시스템 기획서최초 작성 2024.10.10수정 2024.12.11, 2025.03.18

목차 1. 개요 2. 상세 3. 테이블

1. 개요

  • 플레이 지원보상은 접속/접속종료 시간에 따른 보상 지급 시스템을 구현한다.
    • 보상은 클리어한 스테이지를 기준으로 책정한다.
    • StageTable에 각 스테이지별 보상을 입력할 수 있도록 구현한다.
      • 기존 RewardOffline은 사용하지 않는다.

2. 상세

2.1 보상 기준

  • 시간 보상이란 유저의 온라인/오프라인 상태였던 시간을 모두 누적하여 지급하는 보상을 뜻한다.
    • 온라인 보상/오프라인 보상을 구분하지 않고, 플레이 시간(오프라인도 플레이 시간으로 포함)을 기준으로 보상을 지급한다.
  • 시간 보상 지급량은 가장 마지막에 클리어한 스테이지를 기준으로 책정한다.
    • 테이블에 각 스테이지별로 보상을 설정할 수 있도록 구현한다. (최초 접속시간 기준)
    • 이를 위해 StageTable에 보상 설정을 위한 컬럼을 추가한다.
  • 시간 보상은 최대 8시간까지 누적되고, 시간 단위에 따라 서로 다른 보상이 누적된다.
    • 1분 단위로 재화가 누적되고, 10분 단위로 캐쉬와 스킬포인트, 펫 보상이 추가된다.
    • 10분 단위 보상은 RewardTable에 설정되고 10분마다 해당 Pool에서 랜덤으로 보상이 하나씩 선택된다.
시간 단위보상
1분골드, 그릇
10분캐쉬, 스킬포인트, 펫
  • 최대 누적 시간은 기존 오프라인 보상 기능에서 사용되었던 table.VariableTable.Key 값인 RewardOffline_LimitTime을 그대로 사용하여 임의로 조정할 수 있도록 기능을 유지한다. (컬럼 이름은 바꾸는 방향을 제안)

2.2 플레이 지원보상

  • 미수령 시간에 따라 보상이 누적되고, 보상을 수령하는 순간 누적 시간을 초기화한다.
    • 보상은 별도 팝업 UI를 통해 유저 임의로 받을 수 있도록 하고 강제적으로 수령시키지는 않는다.
    • 수령 가능한 보상이 있는 경우 메인 UI에 전용 버튼을 노출시키고 보상이 수령될 때까지 유지한다.
    • 보상을 수령하지 않고 접속을 종료하는 경우 시간을 계속 누적한다.
  • 보상은 보상의 시간 Tic마다 즉시 계정에 보상 정보를 생성한다.
    • 보상 UI 상에 누적된 보상 정보를 미리보기로 보여준다. (보상을 받지 않고 창을 닫을 수 있기 때문)
    • 보상 UI가 열려 있는 상태에서 Tic이 체크되는 경우 보상 정보를 즉시 갱신하여 출력 내용을 변경한다.
  • 아이콘이 노출되기 위한 시간 최소 10분
  • 팝업이 오픈되었을 때, 누적시간이 변경되어 추가 보상이 지급될 경우 처리방법 논의 필요
    • 1안: 팝업의 내용이 갱신되어서 표시된다.
    • 2안: 표시 내용과 상관없이 수령할 때, 추가 지급분과 함께 지급한다.

3.2 StageTable

  • 시간 보상 적용을 위한 컬럼 추가

보상 공식 — 모든 결과값은 소수점 첫째 자리에서 반올림

t = 누적 시간(초) / 60 T = 누적 시간(초) / 600 1분 보상량 = RewardTimePerGold 또는 RewardTimePerVessel 의 값
항목공식결과
1분 보상{ t × 지급량 } × (1 + 증가비율 스탯(%))결과값만큼의 양으로 보상 지급
10분 보상{ T × 지급량 } × (1 + 증가비율 스탯(%))결과값만큼의 횟수로 RewardTimePerItem의 Pool에서 랜덤 선택
