  • 기능 확장형 상품

          • 마지막 상품을 계속 구매가능

UI 및 필요기능

  • 상품표시방법

  • 지급품 여러 개를 구성

  • 판매기간 있음 (show /hide 가능)

    • schedule → sale_date_hide 값으로 show / hide 설정

      • 기간제 상품은 FALSE

      • 상시판매 상품은 TRUE

  • 구매 제한 횟수 : 횟수 제한 있음

  • 구매 횟수 초기화 주기 있음. (0 일 경우, 구매횟수 초기화 안함)

    • 구매완료한 상품의 경우 (초기화 주기가 있을 때)

  • 남은 시간 표기

    • cycle_purchase_reset >0 일 때 표기

    • 다음 상품 갱신시간 ( 구매 횟수 초기화까지 남은 시간) 표시

  • 상품을 구매할 경우

    • 버튼에 [구매완료]처리

  • ‘구매 완료상태’ 상품을 계속노출할 것인지

    • schedule → display_after_purchase

      • TRUE이면 구매해도 계속 표시

      • FALSE이면 구매하면 해당상품 표기 안함

  • UI 타입 구분

    • layout: single

  • 확장 기능

    • TAB.json에서 설정

      • STEP UP

        • package_list[배열].previous_packagage_uid 정보를 통해 해당 상품을 구매하기 위한 조건으로 설정

        • 동일한 텝에 하나의 상품을 구매할 경우 다음 상품이 노출되는 구조.
