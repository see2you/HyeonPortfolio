원본: 3. [작업용] 정액상품

  • 개요문서:[작업용] 인앱상점

특징

  • 상시판매

  • 구매횟수제한 설정

  • 구매횟수 reset 주기 있음 (새로고침 시간)

  • 기간동안 로그인 보상지급 있음

    • 우편으로 지급 (설명에 명시 필요)

  • 당일 로그인 하지않는다면 우편으로 지급되지않음

    • 상품 내용에 로그인하지 않으면 보상을 받을 수 없다는 내용을 명시해야함.

  • 즉시 지급 보상 있음


UI/UX

  • 상품표시방법

  • 구매 시 즉시보상이 지급

  • 일정기간동안 로그인하여 보상을 받음

  • 상시 판매

  • 구매 횟수 제한 있음

  • 구매 횟수 초기화 주기 있음

    • 상품마다 다름

  • 구매상품은

    • 우편l 지급

      • 매일: 로그인 했을 때 우편으로 보상 지급

      • 구매 즉시: 우편으로 발송

  • 유효기간

    • 만료되기전 상품을 구매할 수 있다.

    • 위의 경우 유효기간이 늘어난다.

      • ex)유효기간이 1일남았을 때 정액상품을 추가로 구매할 경우 29일이 된다 ( + 유효기간 28일 짜리)

  • 구매버튼

    • 구매하지 않았을 때

      • [가격]을 표시

    • 구매 했을 때

      • [구매완료] 버튼

    • 수령 기간이 남아 있고 → 구매 하고 연장 가능할 때

      • [연장하기] 버튼

  • UI 구분

    • layout : login

스크립트 가안

  • uid

    • string 값으로 처리하고 수정이 용이하도록 한다.

  • package_name

    • 상품이름

  • sale_text : 사용안함

  • package_desc_1

    • 상품 설명 1

  • package_desc_2

    • 상품 설명 2

  • reward_uid

    • cash_shop_reward.json

      • [0] 배열 즉시 지급 상품

      • [1] 매일 지급 상품

      • 구매 첫날 [0],[1] 동시 지급

  • inapp_code

    • 연결된 인앱가격코드 연결

  • package_image_path

    • 상품 이미지

  • 작성방법

    • tab

  • schedule

    • 판매기간은 서비스 종료일시까지 판매 할 것이기 때문에 장기간으로 설정

    • purchase_count

      • 1번만 구매할 수 있으므로 1로 설정

    • cycle_purchase_reset

      • 구매횟수 초기화 되는 날짜

    • login_package_payment_period

      • 상품을 몇일짜 까지 지급할 것인가
