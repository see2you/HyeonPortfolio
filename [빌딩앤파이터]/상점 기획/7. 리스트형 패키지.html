단일 패키지 (리스트)

  • 상품표시방법

  • 여러 개를 단일패키지 리스트 화

  • 판매기간은 없음

  • 새로고침까지 남은시간으로 표기

    • 구매한도 초기화까지 남은 시간 99일 99:99:99(시/분/초)로 표시

    • 구매횟수 초기화 갱신주기가 없는 상품일 경우 남은시간 표기하지않음

  • 구매 제한 횟수 : 제한 있음.

  • 구매 횟수 초기화 주기 있음. (0일 경우, 구매횟수 초기화 안함)

    • 구매완료한 상품의 경우

      • 다음 상품 갱신시간 ( 구매 횟수 초기화까지 남은 시간) 표시

  • 리스트 내 상품을 구매할 경우

    • 버튼에 [구매완료]처리

  • UI 타입 구분

    • layout: list
