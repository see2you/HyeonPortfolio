원본: 3. [작업용] 하루 특가 상품

하루 특가

  • 개요문서:[작업용] 인앱상점

특징

  • 판매기간 설정

  • 구매횟수제한 설정

  • Step 설정

    • step-up상품구성을 위함

  • 구매횟수 reset 주기 있음 (새로고침 시간)

    • 상시판매 상품을 만들어서 하루 1회만 구매가능하도록 하기 위함.

  • 매일 받을 수 있는 보상이 있음 (무료 가능)

UI/UX

상품표시방법

  • [한번 구매 상품]을 하루 제한적으로 판매

    • 구매횟수 있음

  • 여러 개를 단일패키지 리스트 화

  • 판매기간: 상시판매

  • 구매 제한 횟수 : 제한 있음 (1일 1회)

  • 구매 횟수 초기화 주기: 1일 (오전 6시)

  • 상품을 구매할 경우

    • 버튼에 [구매완료]처리

    • 다음 구매까지 남은시간 표기 23:59:59 (다음 갱신까지 남은 시간)

  • 무료상자는 Tab 스크립트 0슬롯에 배치

  • layout

    • daily_special

스크립트

  • package_normal

  • uid

    • string 값으로 처리하고 수정이 용이하도록 한다.

  • package_name

  • sale_text

  • package_desc_1

  • package_desc_2

  • reward_uid

  • inapp_code

  • package_image_path

  • 상점(tab)과 스케줄 작성

    • tab

      • 무료상자를 0슬롯에 배치

  • schedule

    • 매일 구매 횟수가 갱신될 상품이기 때문에 cycle_purchase_reset → 1 설정

    • 구매해도 다음 갱신까지 유저에게 계속 보여져야하기때문에

      • 남은시간이 표시되어야 하므로 display_after_purchase → true

    • 상시판매될 상품이기 때문에 sale_date_hide → true
