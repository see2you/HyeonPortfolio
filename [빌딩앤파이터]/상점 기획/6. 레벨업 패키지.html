원본: 3. [작업용]레벨업 패키지

레벨업 패키지

  • 개요문서:[작업용] 인앱상점

특징

  • 달성 조건 미션 필요

  • 미션달성(레벨달성)시 보상을 받을 수 있음.

  • 수령버튼 터치하면 → 보상 팝업이 보여지고 인벤토리에 넣어준다.

  • 보상 받기 위해선 선행미션 달성이 필요함.

UI/UX

  • 상품표시방법

  • 구매했을 때, 특정 미션을 달성하면 추가 보상을 지급하는 패키지

  • 상품 판매 기간 종료 시 노출하지않음.

  • 접속하여 수령하기 버튼을 눌러야함.

    • 예시)레벨업 5,10,15,20,25,30,35,40 달성 시 추가보상지급.

  • 퀘스트 시스템을 상점에도 적용해야하는 개발 코스트가 발생 (회의 필요)

    • 현재 판매 중인 상품에 미션 패키지가 있다면 해당 퀘스트를 체크해야하는 상황이 발생

    • 미션 패키지용 스케쥴러가 따로 동작해야하는지 회의를 통해서 구조를 잡아야함

  • 상품을 구매하지않았을 때

    • [수령]버튼에 레드닷 표시하지않음.

    • [수령]버튼을 눌렀을 경우 토스트 메시지 표시

      • uid:cash_shop_need_purchase

  • UI 구분

    • package_type: package_mission
