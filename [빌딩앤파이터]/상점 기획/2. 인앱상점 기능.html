  • 예시: levelup 레아이웃 (레벨업 성장패키지)

특징 별로 상품 타입 구분

  • 단일 / 리스트 타입

    • 판매기간 설정

    • 구매횟수제한 설정

    • Step 설정

      • step-up상품구성을 위함

    • 구매횟수 reset 주기 있음 (새로고침 시간)

      • 상시판매 상품을 만들어서 하루 1회만 구매가능하도록 하기 위함.

  • 단일 페이지 형식 (아바타 상품에 적용)

    • 판매기간 설정

    • 구매횟수제한 설정

    • 같은 group(같은 탭)에 구성될 list 구성

  • 스텝 업 상품

    • 판매기간 설정

    • 구매횟수제한 설정

    • 하나의 탭에 모든 스탭 상품이 모두 노출

    • 선행 구매 패키지를 구매해야만 다음 step의 패키지를 구매가능 ( 첫 step 패키지는 조건없음)

    • 진행 중인 스텝에 포커싱(하이라이트)

  • 하루특가

    • 하루에 한번만 구매할 수 있음

    • 구매횟수가 하루 단위로 리셋 (다음날이면 재 구매가능)

    • 무료보상 상자가 있음

      • 유저 상점 유도용

  • 정액제

    • 상시판매

    • 구매횟수제한 설정

    • 구매횟수 reset 주기 있음 (새로고침 시간)

    • 로그인 보상지급 있음

      • 당일 로그인 하지않는다면 지급하지 않음.

        • 다음날 접속한다면 다음날 보상 지급.

  • 다이아 샵

    • 상시판매

    • 구매제한 없음

    • 초회 보너스가 있는 상품을 구매하면→ 초회 보너스가 없는 상품으로 교체 필요

  • 미션달성 (퀘스트 같은 조건이 필요)

    • 달성 조건 미션 필요

  • 돌발 (퀘스트 같은 조건이 필요)

    • 패키지 노출되는 조건 있음

    • 노출 제한시간있음 (1시간)

  • 매일 다이아 충전 (이벤트 형식 - 퀘스트 같은 조건이 필요)

    • 하루 달성해야하는 충전량이 있음

    • 달성 시 보상 지급

  • 시즌패스

    • 시즌 당 1회 구매

    • 시즌 초기화 시 구매초기화

  • 첫 구매 선물

    • 인앱결제 어떤 상품이라도 결제하면 해당 보상을 받을 수 있음

▶추가 사항

  • 로그인 패키지(정액제)

    • 정액제 상품은 정액 기간이 만료되기전 구매하여 상품기간 연장이 가능하다.

      • ex) 28일 상품은 25일차에 구매 버튼이 활성화 된다.

    • 플로우

      • 정액제 탭을 터치하면 상품을 구매해서 기간을 연장가능하다는 문구

      • [수령 버튼]을 누르면 [기간연장] 버튼으로 보여주기.

▶변경 스크립트

▶tab

  • 탭 표시기간

    • 탭에 포함된 상품을 따라가도록 개발 필요.

    • 탭에 표시되는 상품이 아직 판매 기간이 아니라면 탭은 유저에게 보이지 않는다.

    • 탭에 표시되는 상품이 판매기간이 지났다면 탭은 유저에게 보이지 않는다.

  • uid

  • tab_order : 탭 표시 순서

  • tab_name: 탭 이름

  • layout

    • 상점 UI layout에 따라 표시할 패키지상품을 정렬(스크립트 UID를 참조)

        • package_specific_condition

  • is_sale : 판매되고 있는 상품인가

  • purchase_count: 계정당 구매할 수 있는 횟수

  • cycle_purchase_reset : 구매횟수 초기화 기간

    • 0 : 구매 횟수 초기화 안함

    • N: 해당일차 뒤 차감된 구매 횟수 초기화

      • 예시)

        • 해당값이 1일 때, 23시 59분에 구매했다면 다음날 6시에 초기화

        • 해당값이 1일 때, 00시 59분에 구매했다면 아침 6시에 초기화

  • login_package_payment_period

    • 로그인 패키지 지급기간

    • 로그인 패키지의 경우 구매횟수 초기화 되는 기간과 지급 될 기간이 별도로 필요.

  • diplay_after_purchase

    • 탭의 모든 상품을 구매하면 탭을 삭제할 것인지? 탭을 계속 보여줄 것인지?

    • 탭에 해당값이 TRUE인 상품이 있다면 구매를 완료하더라도 탭을 남겨둔다.

  • sale_date_hide

    • schedule에 설정된 판매기간을 표시하지않음

    • TRUE는 가림

    • FALSE는 표시

  • sale_start_date : 판매 시작 일시

    • 해당 일시가 되면 유저에게 해당 상품이 노출됨.

  • sale_end_date : 판매 종료 일시

    • 구매만 할 수 없음

    • 해당 일시가 지났더라도 유저에 상품이 노출이 될 수 있음

  • display_end_date : 해당 일자가 지나야 비로소 유저에게 노출되지 않는다.
