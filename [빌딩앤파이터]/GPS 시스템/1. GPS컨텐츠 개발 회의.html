  • ‘?’ 오브젝트도 주머니 스폰로직을 사용하여 주머니를 스폰하고 남은 자리에 스폰

    • 감지범위 밖 ‘?’ 오브젝트는 ‘?’ 형태 그대로 스폰

  • 발견된 ‘?’ 오브젝트는 개방범위만큼 가까이 다가가면 자동 개방됨

  • ‘?’ 오브젝트는 개방시 정체가 결정 됨

  • 개방된 오브젝트는 현재 위치와 상관없이 터치해서 즉시 습득가능

    • 열쇠를 요구하는 등의 팝업이 뜨지 않게함 → 모든 비용은 스캐너 충전에 몰빵

  • 모든 GPS 오브젝트는 발견, 개방, 습득 유무와 상관없이 일일초기화시 초기화

예상 플레이 패턴

  • 플로우

    • 월드맵 유저 근처에 스캔을 유도하는 이펙트(반짝반짝)가 보인다.

    • 유저는 스캐너 버튼을 누른다

      • 이때, 스캐너를 작동시킬 위치를 선택한다.

      • 본진선택과 같은 방법 / 빌딩은 모두 가려준다.

    • 유저 근처영역(본진을 설치할 위치 선택과 유사방식)을 터치하여 터치한 헥스를 기준으로 스캔

      • 이때 스캔비용 필요

    • 스캔 후 해당 지역에 숨겨져있던 컨텐츠들이 (?)형태로 보여진다.

      • 회색(?) / 금색(?)

    • 해당 (?)에 근접하면 콘텐츠를 확인 할 수 있고 획득 가능

      • 225m 이내의 컨텐츠는 획득 무료.(스캔비용을 지불한 것으로 비용을 2중으로 지불하는 거부감 삭제)

  • 출퇴근길

    • 스캐너를 사용해야 GPS 콘텐츠를 확인, 직접 걸어가야 개방/습득할 수 있으니 왠만하면 이용안함

    • 퇴근하는 동안 게임 커뮤니티에서 우리 동네 근처 꿀 스폰정보를 수집

  • 퇴근 후

    • 행동력 우선 소모

    • 공성티켓 소모

    • 행동력이 회복되는 것을 기다릴겸 밖으로 나감

    • 집 근처에서 대략적으로 확인할 수 있는 정보와 퇴근길 확인했던 커뮤니티 정보를 종합하여 나갈 방향 선택

    • 해당 방향으로 출발

    • 이동하면서 발견힌트가 확인되는 곳에서 스캐너 사용
      // 예시 스샷

    • GPS 콘텐츠 감지범위내 대상을 즉시 습득

    • 근처 ‘?’ 오브젝트를 개방하러 이동

    • 이후 집에 돌아갈때까지 위 과정을 반복

각 GPS 콘텐츠 상세

스캐너

  • 기존과 달라진 점

    • 스캔 지점을 근처 일정 범위 내에서 자유롭게 선택할 수 있음

  • 충전 및 제한

    • 1일 1회 무료

    • 2회차부터 지정된 자원 요구 → 사용할때마다 요구량 증가

      • 과도한 사용 방지는 요구재화 증감으로 처리

  • 사용 플로우

    • 1. 스캐너 버튼 선택

    • 2. 본진 이전권과 비슷하게 주변 헥스 중 하나 선택 (못 고르는 헥스 없음)

      • 현님 아이디어) 이 상황에서 빌딩 메시도 안보여주면 어떨까? → 터치 못하는 상황 방지

    • 3. 선택하면 확인 팝업이 뜸

      • 터치한 영역으로 화면 포커싱 + 스캔 범위 미리 보여줌

    • 4. 사용을 묻는 팝업에서 ‘예’를 선택하면, 해당 헥스를 중심으로 지정된 범위 스캔

    • 5. 스캔된 범위에 숨긴 상태로 스폰된 콘텐츠들이 ‘?’ 오브젝트 형태로 발견됨

감지범위

  • 기존과 달라진 점

    • 기존엔 스캔 범위를 의미 → 미발견 상태인 ‘?’ 오브젝트의 위치 힌트를 주는 용도로 변경

    • 이 범위 안에 미발견 상태인 ‘?’ 오브젝트가 포함될 경우 해당 헥스에 반짝이는 이펙트 1초간 출력

      • 정해진 주기(ex 30초)마다 감지범위 안에 포함된 ‘?’를 하나 선택 → 해당 위치에 이펙트 출력

      • 마지막으로 선택된 위치 기억, 다음번 선택시에만 해당 위치 제외 (즉, 매번 덮어씀)

개방범위

  • 기존과 달라진 점

    • 기존 역할은 반경 내에 들어온 주머니를 습득하는 것 → 개방된 오브젝트는 어디서나 습득가능

    • 이 반경내에 들어온 ‘?’ 오브젝트를 추가 터치 없이 자동 개방시키는 것으로 역할 변경

‘?’ 오브젝트

  • 기존과 달라진 점

    • 스폰 로직 변경되어서 관련 알람 모두 제거

    • B6 주머니 로직과 비슷하게 19헥스 단위로 스폰

      • 기본 ‘?’ → 특수’?’ 순으로 스폰

      • 한 헥스에 하나의 ‘?’ 오브젝트만 스폰

        • ex) 기본 ‘?’ 가 스폰된 헥스에는 특수 ‘?’를 배치할 수 없음

      • 미발견 상태로 스폰, 스캐너를 통해 발견할 수 있음

    • 발견시 ‘?’ 오브젝트 형태로 등장

      • 기본’?’ 와 특수’?’ 는 외형적으로 차이를 줘야 함 (ex 기본 하얀색, 특수 금색)

    • 다이아를 내고 원거리에서도 개방 가능

    • 개방된 오브젝트는 거리와 상관없이 습득 가능

주머니

  • 기존과 달라진 점

    • 주머니를 직접 스폰하지 않고 ‘?’ 오브젝트 개방시 가중치에 따라 등장 하도록 변경

    • 흐릿하게 보이는 경우 없음 (개방시에는 항상 투명도 0)

  • 레어리티

노멀 레어 유니크

  • 오픈 버전에서는 노멀, 레어, 유니크 3단계까지만 사용 // 하얀색 보따리 형태 유지하고 물음표 색만 변경

  • 전설, 에픽은 제한적으로 사용할 예정 (오프라인 이벤트, 오늘의 뉴스 등)

유물상자

  • 기존과 달라진 점

    • ‘?’ 오브젝트 개방시 가중치에 따라 등장

    • 기존보다 하루에 더 많은 유물상자를 접할 수 있게 됨

  • 레어리티

노멀 레어 유니크

  • 오픈 버전에서는 노멀, 레어, 유니크 3단계까지만 사용

  • 전설, 에픽은 제한적으로 사용할 예정 (오프라인 이벤트, 오늘의 뉴스 등)

유물부하

  • 기존과 달라진 점

    • 유물상자에 포함되어있던 유물부하를 분리 → 월드맵에 해당 부하를 직접 표시

    • O1 기준 개방된 후 즉시 영입 가능

      • 이미 획득한 부하의 경우 카드1장 수량에 해당하는 조각 지급 (조각 변환 비율 적용)

      • 신규 영입시 출력할 대사와 중복 영입시 출력할 대사 구분필요

  • 향후(O2) 계획

    • 획득 방법이 변경 → 3가지 방법 중 유저가 자유롭게 선택

      • 요구 재화(GPS 코인)을 지불 후 즉시 획득

      • 해당 부하와 전투해서 (유저가)승리하면 획득

      • 특정 돌발퀘스트를 수령 → 해당 퀘스트를 성공시 획득

암상인

  • 기존과 달라진 점

    • GPS 코인으로만 물건을 판매

    • 기존보다 암상인을 만날 확률이 높아짐 (자세한건 스폰 로직 참조)

    • 정보 구매 가능

      • 근처 미발견 오브젝트 위치

        • n회 구매 가능, 암상인 스폰지점으로부터 아직 미발견된 오브젝트 위치를 표시

        • 구매시 해당 위치의 오브젝트가 발견 상태로 전환

      • 미러 레이드 정보 // O2 이후 재점검

    • 시트에서 n개째 주머니 생성확률을 지정

      • ex) 위 예시 기준 주머니 1개는 100% 생성하고 80% 확률로 1개 더 생성

        • 여기서 생성 성공하면 60% 확률로 1개 더 생성할지 여부 결정, 이후 반복

        • 실패하면 1개인채로 종료

  • 암상인, 유물상자

    • 둘 중 1개가 ‘?’로 포장되어 그리드당 1일 1개 생성

      • 일일 최초 로그인한 그리드의 경우 유저 주변에 1개 확정 생성

      • 그리드 이동시 해당 그리드에 30분 초과 체류할 경우에 1개 생성

변경(O1)

  • 헥스 19개 묶음으로 배치하는 부분은 기존(B6)와 동일

  • 스폰 위치 (gps.xlsx → pocket_spawn_prob 시트 → gps_obj_count_prob[])

    • 기존 주머니 로직을 활용하여 기본 ‘?’ 오브젝트를 먼저 배치

      • index [0] 에 기입된 확률 참조하여 정해진 개수만큼 스폰

    • 기본 ‘?’ 오브젝트 배치가 끝난 후 남은 헥스에 특수 ‘?’ 오브젝트 스폰 시도

      • index [1] 에 기입된 확률 확률 참조하여 정해진 개수만큼 스폰

      • 한 헥스에는 하나의 오브젝트만 존재 가능 → 스폰이 결정되었는데 남은 헥스가 없을 경우 스폰 취소됨

    • 일일 초기화 단위로 서버 공통

    • 모든 유저가 동일한 위치에서 동일한 ‘?’ 오브젝트 확인 가능

    • 물가 스폰 제외시킴 // 본진 선택 로직 참조

  • 정체 결정

    • ‘?’ 종류에 따라 가중치 (gps.xlsx → obj_open_weight 시트) 기반으로 정체가 결정됨

      • 개방시 선택되지 않은 항목은 다음 개방시 plus_weight 값만큼 가중치를 추가 반영

        • 추가되는 값은 누적, 선택될 경우 추가 값 0으로 초기화 → 일종의 천장

      • 그 날 등장할 수 있는 각 오브젝트의 최대 수는 spawn_limit 로 통제

      • 같은 위치의 ‘?’ 오브젝트에서 개방된 정체는 유저마다 다를 수 있음

  • 오브젝트 표시 단계

    • 아지랑이 (내 주변, 레어리티 표시?)

      • 스캔(내 주변 일정 범위에 가능)하면 물음표로

    • 물음표 (스캔된 범위, 레어리티만 표시됨)

      • 빠른 이동이 아닌 상태로 가까이 가거나 다이아 사용하면 개방됨

    • 주머니, 상자, 암상인.. 등등

      • 어디서든 터치하면 작동. 비용 없음

      • 암상인도 거리 제한 사라짐 (광장상인은 그대로 제한)

  • 구현

    • 생성 위치와 레어리티는 기존 주머니 룰처럼 서버 / 클라 각각 시드로 계산 (아지랑이 단계)

    • 스캔을 하면 스캔 중심 헥스를 서버에서 저장, 목록으로 받아서 범위 계산해서 클라가 표시 (물음표 단계)

      • 스캔한 목록은 일일 초기화 때 초기화됨

    • 가까이 가거나 다이아를 써서 정체를 밝힐때는 서버로 요청, 로그인시 서버가 결정한 목록을 따로 받음

      • 정체를 밝힌 목록은 일일 초기화때 초기화됨

    • 주머니나 상자를 오픈할때도 서버로 요청해서 처리

O2 이후 체크할 것들

그리드 보물

  • 한 그리드에 하나만 존재하는 매우 가치가 높은 GPS 오브젝트

  • 꽤 긴 리셋주기를 가짐

  • 직접 다가가야만 확인 가능

  • 그리드 보물도 ‘?’ 형태로 포장

    • 개방 전까지 그리드보물인지 알 수 없음

디스크

  • 기존과 달라진 점

    • O1 기준 ‘?’ 오브젝트 개방시 디스크가 스폰될 수 있는점만 추가

  • 향후(O2) 계획

    • 개인보상

      • 다른 사람과 접촉하는 것 자체를 꺼리는 유저를 위한 보조 장치

      • 다른 사람과 조합하지 않고 즉시 보상 수령 가능 → 보상은 절반이하로 축소된 형태

    • 디스크 수명시간 존재

      • 이 시간내로 조합하지 못한 디스크는 조합할 수 없고 개인보상만 수령가능

    • 디스크가 조합되고 보상을 받기 전 실제 LP판이 재생되는 듯한 사운드 추가

      • ex) 월광 소나타 디스크의 경우 월광소나타가 짧게 재생되면 좋겠음 // 저작권 고려해야 함

    • 일정 확률로 디스크가 조합된 위치에 추가 콘텐츠가 스폰 (모인김에 뭔가 할 수 있게 유도하는 장치)

      • 그림자레이드

        • 조합에 필요한 인원수에 맞춰 스케일된 난이도 (ex 4인 디스크의 경우 4인 레이드)

      • 원기옥 상자

        • 더 많은 사람이 해당 장소에 모이도록 유도하는 장치

원기옥 상자

  • 디스크를 조합할 때 랜덤하게 생성되는 상자 → 디스크 조합인원 보다 더 많은 인원이 필요 → 사람들 모이게 하는 장치

그리드 뉴스

  • 매일 새로운 느낌을 주게 하기 위한 장치 // GPS 쪽과 밀접하게 연관해서 준비

날씨 관련 기획

  • 눈 & 비가 오면 GPS 콘텐츠 감지범위 증가

  • GPS 콘텐츠 터치 범위 증가 (10m → 1000m)
