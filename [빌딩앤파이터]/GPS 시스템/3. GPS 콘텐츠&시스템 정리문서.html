2. 기획의 목적

    • 월드맵을 탐색하는 느낌이 들도록 개편한다
    • 유저간의 좋은 보상의 위치를 공유하여 지역커뮤니케이션을 활성화 한다

3. 개념 / 용어 정리

    • 개념
        • 스캔을 사용하여 유저 근처에 있는 흔적(발견의 흔적)을 발견하고 근접하여 발견된 콘텐츠의 정체를 알아내고 보상을 획득한다.
              • (아지랑이→ 물음표) (물음표→콘텐츠)
        • 오브젝트 표시 단계
            • 아지랑이 (내 주변, 레어리티 표시?)
              • 스캔(내 주변 일정 범위에 가능)하면 물음표로 바뀐다.
              • 해당상태에서 획득은 불가능하다.
            • 물음표 (스캔된 범위, 레어리티만 표시됨)
              • 빠른 이동이 아닌 상태로 가까이 가거나 다이아 사용하면 개방됨
              • 다이아를 지불하면 획득 가능
            • 콘텐츠 (주머니, 상자, 암상인.. 등등)
              • 어디서든 터치하면 작동. 비용 없음
              • 암상인도 거리 제한 사라짐 (광장상인은 그대로 제한)
        • 구분
          • 구분 설명
          • 발견의 흔적 아지랑이!
              • 유저주변에 생성된 콘텐츠의 위치를 유추할 수 있는 이펙트
          • 물음표 ‘발견의 흔적’이 보이는 위치를 유저가 스캔하게 되면
              • 스캔 범위 내에 있는 콘텐츠가 물음표 오브젝트로 표시된다.
              • 레어리티에 따라서 회색 / 금색 물음표 mesh로 표시된다.
          • 콘텐츠 물음표에 근접하면 콘텐츠의 정체가 밝혀진다.
              • (콘텐츠mesh로 변경된다)
              • 거리가 멀 경우 다이아를 지불하여, 물음표의 정체를 확인하며
              • 즉시 획득 가능하다.
              • 콘텐츠 종류
              • 주머니 CBT
              • 유물상자 CBT
              • 유물부하 CBT
              • 디스크 CBT 포함 안됨
              • 그리드 보물 CBT 포함 안됨
              • 암상인 CBT
    • 용어
        • 미발견
            • 물음표 오브젝트가 월드맵에 표시되기 전 단계
        • 발견
            • 물음표 오브젝트로 표시하는 단계
            • 발견된 (?)오브젝트는 거리가 멀어져도 사라지지 않습니다.
        • 개방
            • 물음표 오브젝트가 콘텐츠로 변경되는 단계
            • 개방된 콘텐츠는 거리가 멀어져도 사라지지않습니다.
        • 스캐너
            • 1일 1회 무료
            • 사용할 때마다 비용 증가 있음
            • 특정지역의 특정범위 내에 존재하는 미발견 콘텐츠를 발견한다.
        • 발견의 흔적
            • 외형 및 설명
              • 지도에 스캔을 유도하는 이펙트가 보인다. (명칭: 발견의 흔적)
              • 어디 헥스인지도 표시 필요.
              • 유저 근처 500m에 표시되며
              • 동시에 모든 미확인 오브젝트가 있는 곳에 표시되는 방향이 아닌
              • 범위 내 존재하는 미확인 콘텐츠 위치에 번갈아가면서 한번씩 보여진다.
        • 물음표 오브젝트
            • 외형 및 설명
              • 정체가 밝혀지지않은 콘텐츠를 물음표로 표시한다
        • 주머니
            • 외형
              • 보상을 얻을 수 있는 오브젝트
        • 유물상자
            • 보상을 얻을 수 있는 오브젝트
            • 레어리티에 따라 색상이 다르다.
        • 암상인
            • 일반상점 / 광장상인에서 구입할 수 없는 상품을 판매하는 상인
        • 유물부하
            • 부하를 보상으로 획득할 수 있음. 단, 보유한 부하의 경우 조각으로 획득
        • 레이드
            • 스캐너가 작동된 영역에서 레이드가 발생 예정에 있다면 알람으로 알려준다.
            • mirror 는 월드맵 곳곳에 자동
            • shadow 는 소환권 사용
            • clan 은 클랜 페이지에서 소환
            • square 는 플레이 인원이 많은 그리드에서 낮은 확률로 소환 (이번 마일스톤에 변경될 수도 있음) 해당 사항이 스캐너로 확인가능

7. 관련 스크립트

    • 월드에 배치
        • 미발견 상태일 때 아지랑이 또는 반짝이는 무언가로 표현
        • 레어리티를 가짐
        • gps_obj_spawn_count
    • 스캔 했을 때
        • 생성 되어진 회색 물음표/ 금색 물음표 레어리티로 표시
    • 물음표에 근접 또는 원거리에서 터치 했을 때 다이아를 지불하면
        • 콘텐츠 메쉬로 변경
        • gps_obj_open_weight
    • 스캔 비용
        • gps_scan_cost.json
        • 최대횟수 초과 시 스크립트의 max 비용을 청구
    • 고정 값
        • gps_constant.json
    • gps_obj_spawn_count.json
        • uid(int) : 구분값, 생성수량
        • gps_obj_count_weight[배열](int) : 생성 수량 가중치 값
        • 헥스 그룹 37개에서 몇개를 생성할지 확률(가중치)로 결정
            • [0] : 3개를 생성할 가중치 2000, 4개를 생성할 가중치 3000, 5개를 생성할 가중치 3000, 6개를 생성할 가중치 2000
            • [1]: 0개를 생성할 가중치 8000, 1개를 생성할 가중치 2000
    • gps_obj_open_weight.json
        • uid (int): 구분값
        • count_weight_index(int): 참조할 gps_obj_spawn_count.json 배열 인덱스
        • obj_uid(string): 생성할 콘텐츠
        • lootbox_uid(string) : 보상 루트박스 인덱스
        • weight(int) : 가중치
        • plus_weight(int) : 스캔에서 생성되지않았을 때, 누적 값 100. (10000 < plus_weight가 되었을 때 생성)
        • spawn_limit(int) : 스캔했을 때 하루 생성 제한양
        • open_mesh_path(string) : 콘텐츠 오브젝트 경로
            • spawn_limit 에 걸리면, -1 (무제한) 에 해당하는 보상을 지급한다.
    • gps_scan_cost.json
        • uid(int) : 구분값, 스캔사용횟수 (하루 1회 무료, 무료는 횟수차감X)
        • scan_cost : 스캔 사용 비용
    • gps_constant.json
        • siege_distance_max_uid(int):
            • building_siege_distance.json // uid: 1 의 siege_distance_max값 참조.
            • 유저 주변 퍼지는 원의 크기
        • scan_range(int) : 스캔범위
            • 스캔을 사용했을 때 콘텐츠가 발견될 반경(m미터)

            • 스캔 비용으로 사용할 아이템 타입
        • scan_cost_uid
            • 스캔 비용으로 사용할 아이템 uid
        • obj_count_weight_material[배열](STRING): gps_obj_count_weight[배열]을 사용하는 물음표의 메쉬
            • count_weight_index에 따라 어떤 메쉬(회색/금색 물음표)랑 연결해줄 것인지 결정이 필요함.
