원본: Google Docs 작업 문서 정리본 · 이미지 내장 · 인터넷 연결 없이 열람 가능

이 문서는 포트폴리오 공개를 위해 재구성·수정된 것으로, 실제 서비스에 적용된 원본과 다를 수 있습니다.

필요파일


        행정구역의 테두리 정보 (구역의 테두리를 구성하는 외곽점들의 집합) DB파일  - shp 파일로 구성됨

해당파일은 WGS84 좌표계로 이루어진 파일이면 좋음.

UTM-K 또는 그외 좌표계 타입을 가진 데이터는 좌표계 변환 작업이 필요함.

우리가 사용하는 OpenStreetMap의 데이터는 WGS84 데이터를 기반으로 하기때문에 UTM-K로 제공된 데이터는 필수로 변환을 해주어야함.

행정구역 별 shp 파일 다운로드 경로

안전행정부에서 지원하는 데이터는 http://data.nsdi.go.kr/dataset (대한민국 최신 행정구역(SHP) 다운로드)

간소화 사이트 http://www.gisdeveloper.co.kr/?p=2332

사용 법

QGIS 를 사용하여 정부에서 제공한 SHP파일 (UTM-K 데이터) WGS84 좌표계 파일로 변환

  1. QGIS 실행합니다.
  2. 상단의 레이어 도구에서 벡터 레이어 추가
  3. 다운받은 SHP 파일을 로드합니다.
  4. 로드된 [행정구역경계] 데이터를 다른이름으로 저장해야합니다.
    1. 좌측하단의 로드된 맵 데이터를 우클릭 -> 내보내기 -> 객체를 다른이름으로 저장
  5. 포멧 형식변환이 필요합니다.
    1. 다른이름으로 저장을 누르면 아래와 같은 창이 나타납니다.
    3. 포멧은 GeoJSON으로 설정
    4. 좌표계를 기본좌표계 WGS 84 타입으로 설정합니다.
      2. 파일이름을 원하는 이름으로 작성 합니다. [...] 버튼을 통해 변경된 파일을 추출할 경로 설정이 가능하며 기본 경로는C:\OSGeo4W64\bin 에 저장됩니다.
      3. 확인버튼을 누르면 완료
  6. 추출데이터 확인
    2. 각 행정 구역의 외곽선을 이루는 점(위 경도 좌표)을 좌표를 얻을 수 있습니다.
    3. 해당데이터 분석 및 그리는 작업이 필요해 보입니다.
