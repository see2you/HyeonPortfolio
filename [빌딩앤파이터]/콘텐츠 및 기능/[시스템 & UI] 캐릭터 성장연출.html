추가 사항

“아이템 장착/ 스킬UP / 레벨업/ 별등급 업 “했을 때, 어떤 능력치가 올랐는지도 표시해 주자. (대표님 디렉션 반영)

<캐릭터와 부하 공통>

  • 연출 공통사용

  • 능력치가 올라가는 사항일 때 공통적으로 해당 연출은 표시한다.

  • 연출이 노출되는 지점

    • 캐릭터 아이템 장착 / 해제 (추천아이템 장착 포함)

    • 캐릭터와 부하 스킬업

    • 예외

      • 마스터 레벨업 / 캐릭터 등급업 / 부하등급업일 경우 해당페이지가 닫히고[확인버튼누르고] 연출을 노출을 보여준다.

        • 마스터레벨업의 경우 현재캐릭터의 성장연출을 노출한다.

  • 연출 사항

    • 상승하는 능력치 표시 (치명타, 공격력, 체력 등)

    • 상승한 점수 종류 표시 (공격점수, 방어점수, 기타점수)

    • 종합 전투력 및 증가치를 표시한다.

    • 캐릭터만 발생하는 능력치 하락연출

      • 아이템을 장착 해제 및 교체 했을 때 능력치가 감소할 경우 감소한 점수만 표시한다.

    • 연출 중 다른 행동 또는 / 다른 페이지 진입시 연출이 취소된다.

      • '아이템 획득 창에서 [장착] 버튼으로 상승 연출 진행 중, [확인] 버튼으로 다음 페이지로 넘어가거나 페이지 표시가 종료될 때에는 해당 아이템에 대한 상승연출이 끝난다.'

    • 전투력이 올라갔을 경우에는 올라간 스텟 + 점수를 표시한다. ( 기준 전투력 )

      • 전투력 변화가 없을 경우에는 연출을 무시힌다.

예시 (블레이드앤소울)

  1. 표시방법

    1. 아이템 장착 / 스킬레벨업

      1. 증가되는 수치를 표시한다.

        1. 표시순서

          1. 상승연출

          2. 하락연출

          3. 아래에서부터 스텟 쌓아가는 형식으로 표시 (최대 3개)

            1. 삭제는 등록된 순서로

          4. 표시할 스텟이 3종이 넘어갈 경우 갱신하고 다시 표시

          5. 스텟표시가 모두 종료되고 마지막으로

            1. 증가된 공격점수 / 방어점수 / 기타점수를 표시.

  2. 적용방향 (아이템 장착 / 스킬업)

    1. 이전 스텟과 비교하여 증가된 스텟이 어떤 것인지 확인하여 표시하는 것이 필요.

    2. 증가되지않는 사항은 표시하지않는다.

    1. 게이지가 점차적으로 증가함

  4. 연출 예시
