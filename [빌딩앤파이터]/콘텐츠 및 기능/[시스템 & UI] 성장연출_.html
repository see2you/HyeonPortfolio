상점에서 카드 획득, 아이템 획득 시 획득 화면 추가

  • 기존 플로우에서 획득 연출 추가 (부하)

    • 부하의 경우 개별구매 시 연출이 빠져있음.

  • 기존 플로우에서 획득 연출 추가 ( 아이템 )

상점에서 아이템 구매 시 추천아이템일 경우 장착버튼 활성화 및 장착 시 성장연출 필요.

  • 장착을 눌렀을 때 성장연출도 표시 해준다.

  • 현재 캐릭터의 아이템이 아닐 경우, 기존과 표시방법 동일. 자동장착버튼 없음.

우편물품 수령 시

  • 획득화면 추가

    • 상점에서 구매할 때와 마찬가지로 추천아이템일 경우 장착버튼 활성화 및 장착 시 성장연출 필요.

      • 장착을 눌렀을 때 성장연출도 표시 해준다.

      • 현재 캐릭터의 아이템이 아닐 경우, 기존과 표시방법 동일. 자동장착버튼 없음.

  • 플로우


빌딩을 획득 시, 관련 부하&전직 강화표시

의도:

  • 빌딩을 획득 했을 때, 해당 빌딩으로 효과를 받는 액터를 보여준다. (액터들이 얼마나 더 강해지는지 보여주고자 한다.)

  • 획득한 빌딩의 생산품량을 표시한다.

표시되어야 하는 것들

  • 이전 소유자 닉네임

    • 누구에게서 빌딩을 빼앗아 왔다.

  • 획득한 빌딩 이름

  • 획득한 빌딩 이미지

  • 빌딩 특성표시 ( 아이콘 / 이름 / 적용효과 )

    • 버프일 때 적용되는 액터 리스트 & 효과 표시

      • 문서 하단에 정리

    • 생산품일 때, 생산량 표시

      • 시간 값: building_constant.json 의 temp_product_attr_interval (분으로 되어있음-> 시간으로 변경필요)

      • 생산되는 물품설명 : (시간값)시간 마다 (building_production_attr.json name값) 생산량

      • 생산량:

        • building_production_attr.json의 product_uids[n]에 해당하는 building_product.json의 amounts[레벨] 값.


버프되는 액터 표시방법

  • 적용되는 액터들을 리스트로 표시.

  • 리스트가 있을 때와 없을 때

    • 정렬기준

      • 적용된 전투력(전체기준)으로 내림차순 정렬.

      • 증가량 표시

        • 현재빌딩 획득 후 증가되는 전투력 표시 필요.

        • 기존 적용되던 버프가 있을 경우 그 값은 표기대상이 아님.

      • 적용되는 액터가 없을 경우 표시 안함.

      • 획득한 빌딩의 버프효과가 적용된 전투력을 기준으로,

전투력이 높은 순서대로 버프를 적용받는 액터( 캐릭터 / 부하)를 내림차순 정렬

  • 시안

  • 표시 사항

리스트 항목 터치 시, ‘상세정보창 이동 &, 툴팁 기능’ 없음.
