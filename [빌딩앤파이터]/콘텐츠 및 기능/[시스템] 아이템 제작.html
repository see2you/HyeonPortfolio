제작

  • 만렙컨텐츠

  • 제작서 아이템 추가 : 재료가 있으면 장비를 제작할 수 있는 아이템. 1회성 소모품.

  • 제작서를 소모품 아이템으로 만든다.

아이템 아이콘

제작 ux 방향

  • 1안 (디렉션)

    • 아이템 선택시 노출되는 팝업에서 제작하는 아이템의 정보와 재료아이템의 정보를 노출한다.

해당 마일스톤에서 진행할 아이템제작

  • 제작전용템을 구분한다.

    • 제작은 인벤토리에서만 가능하다. (우편, 가판대등 사용불가)

    • 레시피를 활용해서 재료를 모아서 제작할 수 있도록 한다.

    • 사용된 제작서(레시피)는 제거(삭제)된다.

    • 제작은 1회에 1개의 제작서를 사용한다.

    • 성공확률은 100% (추후 변경될 수 있음)

    • 특성은 랜덤으로 붙는다. (기존과 동일)

      • 추후 특성을 선택해서 넣을 수 있는 방향은 어떨지 고민→ 옵션 변경 컨텐츠로 푼다.

  • 추후 구현될 수 있는 사항

    • 재료템 강화레벨 유지.

    • 재료아이템에 상관없이 아이템 제작

      • 파츠와 레어도만 맞으면 재료로 사용할 수 있게 한다.

    • 일괄제작

UI / UX

  • 제작될 아이템 표시방법

  • 아이템 팝업을 2개 노출한다.

    • 좌측팝업

      • 제작될 아이템

        • 레벨

        • 이름

        • 아이콘

        • 레어리티

        • 기본 스텟

        • 특성

          • 특성은 공개하지 않음.

    • 우측팝업

      • 제작서 아이템

        • 이름

        • 레어리티

        • 수량

        • 재료 리스트

          • 최대 3 ~ 4개 (추후 변경될 수 있음)

            • 이름은 좌측정렬

            • 수량은 우측정렬

            • 이름은 레어리티 색상과 동일하게 표시

            • 필요한 재료수량

              • 부족할 경우 붉은 색표시

              • (보유량 / 필요량)

            • 제작서는 재료에 표기하지 않는다.

보유한 장비가 재료에 필요한 개수보다 많을 경우

  • 규칙

    • 장착한 장비는 재료로 사용할 수 없다.

    • 인벤토리에 재료가 있을 경우 전투력이 낮은 아이템이 재료로 사용된다.

      • 장착한 장비와 인벤토리에 장비가 모두 있을 경우 (총 2개 이상) 인벤토리 아이템을 제작 재료로 사용한다.

    • 재료로 사용되는 아이템이 모두 인벤토리에 있고, 전투력이 동일하다면 랜덤(먼저획득한 아이템이 재료로 사용)으로 재료로 사용된다.

    • 장착한 장비를 재료로 사용하려 할 때 토스트 메시지를 보여준다.

      • recipe_material_installed_item

        • 장착한 장비는 재료로 사용할 수 없습니다.

        • 필요한 토스트 메시지

          • 우측팝업 아이템의 공개되지 않은 특성을 누를 때

            • ‘특성은 랜덤으로 부여됩니다.’

            • uid : item_option_touched_not_mine

          • 활성화 되지 않은 ‘제작’ 버튼을 누를 때

            • ‘제작조건을 만족하지 못했습니다.’

            • uid : recipe_material_lack

데이터

  • consumable_item.json

    • 신규 아이템 추가 : 아이템 제작서

    • type : cnsmtype_recipe (추가)

    • 스택형

    • recipe_group uid (추가)

  • recipe_group.json (신규추가)

    • uid (string)

    • cost(int) 제작비용 : ri_assets / assettype_gold

    • reward_item_type (string) 제작될 아이템 타입

    • reward_item_uid (string) 제작될 아이템 uid

    • reward_item_amount (int) 제작될 아이템 갯수

    • recipe_material_type[n] (string) 재료타입

    • recipe_material_uid[n] (string) 재료 uid

    • recipe_material_amount[n] (int) 필요한 재료 수량

    • 추후 추가될 수도 있는데이터

      • 제작확률

  • 데이터 작성시 주의 사항

    • recipe_group.json

      • 재료에 사용되는 아이템을 다른 배열에 동일하게 사용하도록 입력하지 말 것.

      • 재료는 3종을 넘기지 않을 것 (B2)

        • 추후 ui변경시 배열이 늘어날 수 있음.

        • ui 표시가능 수량 변경될 수 있음.

이하 2안 (폐기사항)

  • UI에서 신경써야할 것

    • 붙을 수 있는 특성(옵션)을 확인 할 수 있어야한다.

      • 제작의 목적.

    • 재료 아이템을 터치했을 때, 팝업을 노출하여 아이템의 정보를 보여준다.

    • 다만, 재료 아이템이 장비일 경우, 특성정보는 보여주지 않는다.

      • 같은 이름의 다른 특성을 가진 장비를 여러개 가지고 있을 수 있음.

  • 추가될 수 있는 아이디어 (b2이후)

    • 아이템을 제작할 때 특성을 선택하여 부여.

    • 제작 성공확률

  • 제작용 전용 ui를 제작 필요.

    • 팝업으로 할 것인지, 페이지로 할 것인지 결정 필요.(강화는 페이지 형태)

  • 필요사항

    • 아이템 선택시 팝업.

    • 제작에서는 장비도 보유사량이 보여질 수 있어야 함.

  • 한번에 제작할 수 있는 최대수량 제한

    • 필요량 / 보유량 텍스트가 오버될 수 있음.

    • 인벤토리 사이즈 등.

  • 레시피 목록

    • 보유한 레시피일경우 활성화

    • 보유하지않은 레시피일 경우 비활성화

    • 레시피를 터치시

      • 제작에 필요한 레시피 재료가 보여진다.

  • 데이터

    • consumable_item.json

      • 신규 아이템 추가 : 아이템 제작서

      • 스택형

      • 장비아이템 uid 또는 recipe_group uid (신규)

    • equip_item.json

      • recipe_group (string) 컬럼추가, recipe_group.json의 uid 참조

    • recipe_group.json (신규추가)

      • uid (string)

      • recipe_material_type[n] (string)

      • recipe_material_uid[n] (string)

      • recipe_material_amount[n] (int)

      • 추후 추가될 수도 있는데이터

        • 제작확률

    • 제작할 아이템의 특성리스트

      • 참조값

        • equip_item.json: equip_setting_uid

        • equip_setting.json: equip_attr[n].uid equip_attr[n].weight

        • equip_attr.json : 특성데이터
