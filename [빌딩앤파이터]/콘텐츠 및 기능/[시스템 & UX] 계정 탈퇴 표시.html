개요

    • 탈퇴 완료된 유저의 인터랙션을 정리
    • 탈퇴한 유저의 경우 유저닉네임 표시방법

처리 방안

    • user_uuid를 획득할 수 없는경우 (탈퇴한 유저의 정보) ??? 표로 표시
    • 탈퇴된 유저 데이터가 개발사 데이터에 남아있을 때 처리사항
    • 채팅
      • 기록이 남아있는 채팅에서 유저의 닉네임은 [???]로 표기한다.
        • 해당되는 채팅--> 클랜채팅
      • 유저 인터렉션
        • 탈퇴한 유저의 정보를 보기위해 팝업을 오픈 할 경우 토스트 메시지를 노출한다
          • 터치 시 토스트 메시지
            • withdrawn_user // 탈퇴한 유저입니다.
    • 여행자 가이드
      • 누적세금
        • 탈퇴한 유저의 세금은 유지.
      • 인구
        • 탈퇴한 유저는 인구 수에서 제거되지 않습니다.
      • 오늘의 인물
        • 이미 선정된 오늘의 인물이 탈퇴처리된 유저일 경우
          • 닉네임 ???로 표기
        • 다음 취합 때 탈퇴한 유저는 오늘의 인물이 선택될 때 후보군에서 제외합니다.
    • 동네마켓
      • 상품 목록에서 탈퇴유저의 상품은 취합되지 않음.
      • 이미 목록에 포함되어 있다면 가판대 진입을 막는다.
        • 토스트 메시지
          • 터치 시 토스트 메시지
            • withdrawn_user // 탈퇴한 유저입니다.
    • CCTV
      • 기록에 남아있는 유저의 공성기록에 탈퇴한 유저 닉네임은 ???로 처리
    • 토너먼트
      • 탈퇴한 유저 정보는 제거된다.
      • 해당 유저는 상대로 출현하지 않는다.
      • 매칭 리스트에서 배제 시킨다.
    • 채굴
      • 탈퇴한 유저는채굴에 참여할 수 없음
        • 유저는 탈퇴되기까지 몇일간 유예기간이 있어서 채굴에 이미 참여되어있어도 탈퇴가 된 상황은 아니여서 기존 채굴 룰대로 진행.
          • ex) 11일에 탈퇴를 했지만 14일 후 탈퇴가 되기때문에 11일에 진행 되는 채굴에 참여가 되어있다면 그대로 진행됨
    • 클랜
      • 클랜장
        • 클랜장의 경우 일주일동안 접속을 안하면 클랜원으로 강등됨. (현재 7일이고 수정가능)
      • 클랜원
        • 삭제되어 표시되지 않음.
      • 클랜 뉴스에 남아있는 닉네임은 변경하지 않는다.
    • 팔로우
      • 팔로우 유저
        • 캐릭터명을 ???로 표시
          • 터치 시 토스트 메시지
            • withdrawn_user // 탈퇴한 유저입니다.
      • 팔로우 추가
        • 유저 이름을 입력할 때 검색되지 않는다.
          • 토스트 메시지
            • follow_not_found_user // 해당 유저를 찾지 못했습니다.
    • 랭킹
      • 랭킹 취합 때, 탈퇴 계정은 취합하지 않는다
      • 이미 취합된 데이터일 경우
        • 해당 유저의 닉네임을 '???'로 표기합니다.
        • 다음 취합 때 해당유저의 데이터는 보여주지 않습니다.
    • 빌딩
      • 탈퇴한 유저는 본진을 제외하고 빌딩의 소유권을 다 날려버린다.
        • 탈퇴한 유저를 공성하려고 할 때 메시지를 노출한다.
      • 에픽 빌딩을 보유한 유저가 탈퇴할 경우
        • 소유권을 뺏으며, 매칭되지않는다.
    • 부하 평가
      • 탈퇴한 유저가 남긴 평가
        • 시즌마다 정리될 예정
          • 유저닉네임 변경 및 히스토리를 삭제하지는 않음
        • 유저 인터렉션
          • 유저정보팝업을 노출하지않음
          • 터치 시 토스트 메시지
            • withdrawn_user // 탈퇴한 유저입니다.
    • 우편
      • 탈퇴한 유저가 보낸 우편의 유저의 닉네임을 [???]로 표시
    • 가판대
      • 탈퇴한 유저의 가판대 진입을 막습니다.
        • 해당 유저 터치 시 토스트 메시지를 노출합니다.
          • withdrawn_user // 탈퇴한 유저입니다.
      • 만약, 탈퇴한 유저의 가판대에 진입 했을 때, 탈퇴한 유저의 판매상품을 구매 터치 시,
        • 토스트 메시지를 노출합니다.
          • uid: withdrawn_user_shop
          • text: 탈퇴한 유저의 가판대 상품은 구매할 수 없습니다.
