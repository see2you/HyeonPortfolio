1:1 채팅

    • 이미지
    • 귓속말 리스트 UI 음소거
    • 귓속말을 나눈 유저와 '방(room)'이 생성
            • 레드닷 표시
            • 레드닷 표시 안함
        • 귓속말 기능 끄기
            • 귓속말 받음
              • On시 토스트 메시지
              • uid:
              • text: 귓속말 기능을 On했습니다.
            • 귓속말 받지 않음
              • 전달된 귓속말은 삭제하지않음
      • 귓속말 이력이 없을 경우 내역없음을 표시
              • Off시 토스트메시지
              • uid:
              • 귓속말 기능을 Off 했습니다.
        • 귓속말 나가기
            • 내용을 모두 삭제하고 목록에서 제거
            • 나에게만 목록이 삭제되고, 상대방의 귓속말 방은 사라지지않음
        • 귓속말 레드닷
            • 레드닷이 뜬 채팅방을 터치하여 귓속말 채팅방에 입장했을 때 삭제
    • 귓속말 채팅방 UI 입장 시
            • 포커싱
              • 최근 메시지가 제일 하단에 노출되게 포커싱
              • 내가 채팅을 보냈다면 내가 최근 보낸 메시지에 포커싱 이동
              • 읽은 부분까지 포커싱은 예외처리가 많으므로 스팩에서 제외
        • 대화방 나가기 버튼
        • 해당 유저 귓속말 음소거
            • 레드닷 표시
            • 레드닷 표시 안함
        • 해당 유저 차단
              • 해당 버튼을 눌렀을 때 팝업
              • [차단하기] 눌렀을 때
              • 토스트 메시지
              • uid:
              • text: [유저닉네임] 차단 하였습니다.
              • 대화방 삭제 및 대화방을 표시하지않음 → 귓속말 리스트 UI로 이동
              • 차단유저의 귓속말을 수신하지 않음
              • 차단 유저의 우편을 수신하지않음
              • 기존 우편함에 수신된 우편은 유지
        • 채팅UI에서 표시 방법
            • 귓속말 태그 필요
        • 전체 채팅 탭에서 표시 방법
            • 귓속말 태그 표시
