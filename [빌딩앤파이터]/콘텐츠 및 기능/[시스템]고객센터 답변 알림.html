개요

    • 1:1 문의 답변 인게임 알림기능은, 게임에 접속 중이기에 푸시를 수신하지 못하거나 푸시 수신을 차단할 경우 인게임에서 더 빠른 답변 도착을 확인할 수 있는 기능
    • [고객] TOY 고객센터로 1:1문의 접수합니다.
    • [운영] 조작가 1:1 문의 답변을 작성합니다.
    • [TOY] 답변 등록 10분 후, [TOY 서버] → [게임] 으로 문의한 사용자의 NPSN 값과 게임 지역 데이터 를 전송합니다.
    • [게임] 문의한 고객에게 인게임 내 알림(우편함 또는 시스템 메시지)을 게시합니다.
    • [고객] 알림 클릭 시 TOY 고객센터 1:1문의 메인 페이지로 이동합니다.
    • [게임] 특정 조건 (알림 클릭/문의 페이지 요청/알림을 기한 종료) 만족 시 알림을 삭제합니다.

알림 구현

    • 게임 내 알림은 시스템 알림 메시지로 등록되게 합니다.
      • 알림 메시지 터치 시 TOY 고객센터 1:1 문의 메인 페이지로 바로 이동하도록 구현합니다.
    • 알림 구성
      • 텍스트 : 1:1 문의 답변이 도착했습니다.
      • uid: alarm_repeat_customer_answer
      • 유효기간 7일 (10080분)
      • 언락조건 없음
    • 알림 터치 시 처리
      • 유저가 게임 내에서 답변 알림을 터치 할 경우, TOY 고객센터 1:1 문의 페이지로 다이렉트 이동
    • 알림 삭제 조건
  • 상태 설명
  • 알림이 만료될 때 답변 등록으로부터 기본 7일 동안 알림을 보고하고, 7일 이후에는 알림을 삭제 처리합니다.
  • 고객에게 알림이 2개 이상인 경우 기한이 만료된 알림만 삭제합니다.알림은 운영/개발/사업 조율에 따라 변경 가능합니다.
  • 알림을 클릭하여 고객센터 메인 페이지로 이동했을 때 실제로 답변을 확인했는지 여부는 확인하지 않고 고객 센터 메인 페이지에 접근하면 해당 npsn에게 표시된 모든 알림이 삭제 처리됩니다.
  • 유입 경로: 알림 터치 > [TOY 1:1 문의 메인 페이지]
  • 알림을 통하지 않고 고객센터 메인 페이지로 이동했을 때 다른 경로 이미지 답변을 확인하지 않아도 알림이 유지되는 경우를 방지하기 위해 해당 npsn이 고객센터 메인 페이지에 저장하면 모든 알
  • 림을 삭제 처리합니다.
